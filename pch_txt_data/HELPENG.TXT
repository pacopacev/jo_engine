[Dlg_G01]

  X,Z : For an absolute command ,coordinates of an end point 
  U,W : For an incremental command ,distance the tool moves.

  ,C : add a chamffer C at end corner

explanations :

feedrate specified in F 
2. The feedrate commanded by the F code is measured along the
tool path

   1. From start point (S) ,rapid travel to Nth cutting position
   2. Threading cutting to coordinate Z 
   3. Rapid travel extract to Start X(X direction)
   4. Rapid travel go to start point(S)

   1. From start point(S) ,rapid travel to precision dimension
      (X direction to X coordinate)

[ToolSetting]
X axis tool offset(length) :
  Measure input:
1. Spindle on ,By manual operation or MPG handle feed 
  ,Z direction to cut workpiece
2. Z direction extract from workpiece 
3. Measure workpiece diameter of cutting surface , set
  this value as the measured value along the X-axis for
  the desired offset number .
4. The offset value is automatically calculated and setted .
5. According the tool tip position "upper + ,down - " 
  designate the value sign
EX: tool tip  position is located X+ area ,this value
    is positive .

Direct absolute input : 
1. execute manual reference positon return .
2. Tool position offset values can be set by manual moving 
  the tool until it touches the workpiece coordinate zero .
3. Input machine coordinate of current position to desired
  tool X offset value
EX: A **.***

Incremental tool offset values input :
1. after tool offset values is set and a little bit error
2. use incremental offset input to adjust tool values
EX: I **.*** 

Z AXIS tool offset values :
 Measure input:
1. Spindle on ,By manual operation or MPG handle feed ,X 
   direction to cut workpiece
3. X direction extract from workpiece 
4. set "ZERO SHIFT" value to Z axis tool offset of the
  desired offset number .
5. The offset value is automatically calculated and setted .
6. According the tool tip position "right+ ,left-"
  designate the value sign
EX: tool tip  position is located Z+ area ,this value 
    is positive .

Direct absolute input : 
1.execute manual reference positon return .
2. Tool position offset values can be set by manual moving
   the tool until it touches the workpiece coordinate zero .
3. Input machine coordinate of current position to desired 
   tool X offset value
EX: A **.***

Incremental tool offset values input :
1. after tool offset values is set and a little bit error
2. use incremental offset input to adjust tool values
EX: I **.*** 

X,Z AXIS tool wear compensate
1. compensate sign rules : 
"the same sign with the tool tip desired adjust direction "
EX1: tool is located at X+ area ,and workpiece machining 
    size too large. Tool tip should be X- direction adjust
    ,then tool wear compensation should be negative .
EX2 : tool is located at Z+ area ,and workpiece machining 
    size too large. Tool tip should be Z- direction adjust
    ,then tool wear compensation should be negative .
2. X tool wear compensate is diameter designation
3. Z tool wear compensate is radius designation
