動作說明 :
動作一.
  第一刀粗車 : 
    1. 刀尖從加工起點(S) ,快速定位到第一刀切削深度 D
    2. 開始車牙到程式終點 Z 軸座標 
    3. 快速定位抽刀到起點 X 軸座標
    4. 快速定位回到加工起點(S)
  第二至第 N 次的粗車 :
    1. 從加工起點(S) ,快速定位到第 n 次切削位置
    2. 開始車牙到程式終點 Z 軸座標 
    3. 快速定位抽刀到起點 X 軸座標
    4. 快速定位回到加工起點(S)
  精加工 : 
    1. 從加工起點(S) ,快速定位到最終尺寸(程式 X 軸座標)
    2. 開始車牙到程式終點 Z 軸座標 
    3. 快速定位抽刀到起點 X 軸座標
    4. 快速定位回到加工起點(S)
  加工倒角設定 :
    *. 倒角量設定 :
       畫面設定參數 r ,設定倒角量 ,單位是 0.1 螺牙
       畫面不設定 r ,則由系統參數 4043 自動設定
    *. 倒角角度 :
       控制器會依程式中的牙高設定 ,自動計算倒角角度  
 參數說明 :

第一頁參數 :

  X(U)：終點X軸座標(牙底)
  Z(W)：終點Z軸座標(牙底)
  R(i)：斜螺紋高度半徑差(i=0 或不設時 ,為直螺紋)
  P(k): 螺牙高度  
  Q(d)：第一回切削深度
  F：公制螺紋導程 ,單位是每牙幾 mm
  E: 英制螺紋導程 ,單位是每英寸幾牙

第二頁參數 :
  P：          // Modal code ,永久有效
   K : 精車次數，可由系統參數4044號設定。
   C ：倒角退刀長度，可由系統參數4043號設定。
   A ：刀尖角度，可由系統參數4042號設定。
   D：最小切削深度 ,可由系統參數4045號設定
   B：精車預留量,可由系統參數4041號設定

註 :下列情況會異警 :
  1. a 在規定值以外會發警報(a=0,29,30,55,60,80)
  2. 螺牙的高度比到螺紋底部 X 軸移動大時 
  3. 第二頁參數若不設定 ,則會以控制器內部參數值
     為加工值

[Dlg_G96]
指令格式 : G96 S_ ;
說明 : G96等表面切削速度控制ON ,等表面切削速度是位址S後設定周速(刀具及工件間的相對速度)，配合刀具位置計算主軸轉速，使周速固定在指定值。
參數說明 :
S : 為表面切削速度，即表面線速度維持一定，單位是M/MIN或FEET/MIN。,因此 ,同樣的 S code ,在半徑較大時 ,主軸的轉速會較低 ,反之 ,離中心越近 ,主軸轉速越高(表面速度=主軸轉速*半徑)

[NetSetting Standard]
一般網路設定方式：

控制器名稱：	
	此控制器在網路內的名稱, 不可與網路內其他PC或控制器相同, 
	預設為CNC

位址設定：	
	此控制器在網路內的IP位址, 不可與網路內其他PC或控制器相同, 
	預設值為210 20 98 21
	設定方式建議
	(1)與PC一對一連接時, 修改PC的IP位址設定為210 20 98 20
	(2)當有內部區域網路時, 請網路管理者提供一組IP並設定到這個欄位

子網路遮罩：	
	此控制器在網路內的子網路遮罩, 預設值為255 255 255 0
	設定方式建議
	(1)與PC一對一連接時, 修改PC的子網路遮罩為255 255 255 0
	(2)當有內部區域網路時, 請網路管理者提供子網路遮罩

連線PC名稱：	
	控制器要連接的PC名稱, 預設值為Young
	設定方式建議
	(1)與PC一對一連接時, 修改PC的電腦名稱為Young
	(2)當有內部區域網路時, 請網路管理者提供要連線的電腦名稱

連線目錄名稱：	
	控制器要連接的PC所分享出來的資源名稱, 預設值為Public
	設定方式建議
	(1)與PC一對一連接時, 修改PC的分享資源為Public
	(2)當有內部區域網路時, 請網路管理者提供連線PC的分享資源名稱
	
網域網路設定方式：
	(1)請網路管理者先將要連線的PC改為工作群組設定
	(2)依一般網路設定方式將PC與控制器連接起來
	(3)再將要連線的PC改回網域設定

[NetSetting Advance]
工作群組：
	控制器所在的工作群組名稱, 預設為SYNTEC
	設定方式建議
	(1)與PC一對一連接時, 修改PC的工作群組為SYNTEC
	(2)當有內部區域網路時, 請網路管理者提工作群組名稱

關閉DHCP：
	控制器是否要啟動DHCP功能, 預設為1：關閉
	設定方式建議
	(1)與PC一對一連接時, 建議不修改使用預設值
	(2)當有內部區域網路時, 且網路內有使用DHCP伺服器時可以
	   設為0：開啟

重設網路密碼：
	控制器開機時會依照連線使用者所設定的密碼來登入控制器, 在
	第一次設定時會用enter鍵來表示不需要詢問密碼, 若有設定密碼
	則每次開機時都會停下等待密碼輸入, 此時可將此欄位設1, 下次
	開機時會要求使用者重設密碼

連線使用者：
	登入控制器的使用者名稱, 同時也是用來進入連線PC的使用者名稱, 
	預設為CNC

連線密碼：
	連線PC對連線使用者所設定的密碼, 預設為空白, 一般而言不需要密碼

[ToolSetting]
X軸刀長
  量測: 1.以手動方式，沿Z軸方向切削，然後沿Z軸方向退出。
        2.以游標尺量測工件直徑，將直徑值依“上正下負”規
          則輸入，輸入後控制器會根據當時的X機械座標，自
        　動計算出X軸方向刀長顯示在螢幕上。
        3.上正下負的規則為：當刀尖在主軸軸心上方切削稱為
        　上方，此時以正值輸入，反之，當刀尖在主軸軸心下
        　方切削稱為下方，此時以負值輸入(ex: X**.***)    
  絕對: 1.將刀尖移到主軸軸心的位置 ,將目前的機械座標值 ,直
          接輸入到畫面 X 軸刀長的位置(ex:A**.***)
  增量: 1.直接將刀長誤差量 ,以增量的方式加到目前的刀長值 
          (ex: I**.***)

Z軸刀長
  量測: 1.以手動方式，X軸方向切削，然後沿X軸方向退出。
        2.輸入零值，輸入後控制器會根據當時的Z機械座標，
        　自動計算出Z軸方向刀長顯示在螢幕上(ex: Y**.***)
  絕對: 1.將刀尖移到主軸軸心的位置 ,將目前的機械座標值 ,直
          接輸入到畫面 X 軸刀長的位置(ex:A**.***)
  增量: 1.直接將刀長誤差量 ,以增量的方式加到目前的刀長值 
          (ex: I**.***)

X軸磨耗補正量
        1.其符號規則依“希望刀尖向下修正為負，向上修正
          為正”輸入。例如：刀子在工件上方，工件直徑太大
          時，刀尖應往下補正，因此符號為負值 
 
Z軸磨耗補正量
        1.其符號規則依“向左為負，向右為正”輸入。
	  例如：刀子在工件右方，工件長度太長時，刀尖應
	  往左補正，因此符號為負值。

工作座標偏移設定

系統預設為增量輸入, 加工中禁止輸入
加工程式中執行到G92會改變偏移量的設定值

增量輸入
　將游標停在偏移量的 X軸或 Z軸欄位, 從Input line輸入偏移量enter
　後會將輸入值會以增量方式與現在的偏移量及絕對座標計算後
　填入並顯示到偏移量下的 X軸或 Z軸欄位 

計算方式：
	新偏移量 = 現在偏移量 + 絕對座標 - 輸入值

絕對輸入
　從Input line輸入 X***或 Z***會直接填入並顯示到偏移量下的 X軸
　或 Z軸欄位

輸入完成後, X軸及Z軸偏移量計算後會填入系統偏移量(#1901, #1903)

[ALARM21005]
1.說明:
      控制器送出過高的指令數。

2.可能原因:
      (1)DDA軟體時間(補間時間)設置太長。
      (2)運動速度太快。 
      (3)伺服解析度設定太高。
      (4)背系補償量或節距補償量太大。
      (5)啟動前饋補償功能。

3.排除方法:
      (1)降低軟體補間時間設定(CNC參數3203)，建議不低於1500。

      (3)降低伺服解析度設定測試。(驅動器與CNC參數61~80) 
      (4)若有設定機構補償常數(CNC參數1401~1420)，取消機構補償做測試，若是則
         設定適當之機構補償時間常數。
      (5)若有前饋補償 (CNC參數581~600)，取消前饋補償做測試，若是則降低或關閉

      (6)請聯絡機械廠人員處理。

進階說明：
      新代控制器為了達成多軸同動控制，採用了DDA(Digital Differential 
      Analyzer)法則的數學方法， DDA的Cycle Time由參數3203補間時間設定，
      每一軸向指令在一個DDA的Cycle Time內最多允許送出2047個脈衝訊號，
      超出此範圍控制器就會發出DDA指令超過之警報訊息。

[ALARM21008]
1.說明:
      控制器停止對某個軸向指令輸出1秒後隨時檢查回饋指令量與輸出指令量的誤差量
      是否在預定誤差範圍內，如果不在此範圍內，則有遺失位置警報

2.可能原因:
      (1)機構問題。 
      (2)控制緊急停止的繼電器接觸不良。
      (3)CPU板送給軸卡的資料遺失(cpu板有問題，軸卡有問題，cpu板和軸卡接觸不好)。
      (4)控制器伺服線有接觸不良或斷線。
      (5)驅動器到馬達的動力線接觸不好或者斷開。
      (6)馬達編碼器進油。
      (7)編碼器回授線松脫或斷掉。
      (8)局部干擾。

3.排除方法:
      造成此警報的原因大體可以分為電控和機構兩個方面的原因。
      當發生位置遺失警報，觀察診斷畫面的系統資料8，9，10號參數的值，
      如果都為零，一般是機構的問題：如果有不為零的，一般就是電控的問題。

  機構方面的原因：
      (1)如果確定是機構問題，並且無驅動器警報。一般來說，應該是機床缺少潤滑，
         靜摩擦力太大。此時應該檢查機構是不是有卡住及潤滑系統是否良好
      (2)控制器有警報發出，並且伴隨著驅動器警報。此時可能是床台卡死或者
         伺服系統有問題，如果關電重開問題依然存在很明顯，無法動作，應更換伺服
         或者馬達。如果是機構卡死，需要聯繫機械廠家支援

  電控：
      (1)觀察過8，9，10號參數之後。就做尋點動作(不須重新開機)，尋完原點後，
         觀察24，25，26號參數和40，41，42號參數，如果24，25，26號參數中有不為零的
         ，則回授回路有問題。
      (2)如果40，41，42中有不為零，就是控制器到馬達的線路中有指令丟失。
      (3)如果24，25，26和40，41，42都有不為零的，則信號被干擾的可能性比較大，
         具體表現為在加工中，8，9，10號參數的數值漸漸變大。
         具體故障點可能是cpu板和軸卡接觸不好造成的。可依次換cpu板和軸卡試試。
      (4)如果是控制器到馬達的發動電路有問題，先檢查驅動器線和動力線。
         具體辦法是把懷疑有問題軸相的驅動器線和動力線和其他沒問題軸相的驅動器線
         和馬達線對換，看警報會不會跑到別的軸相去，如果跑到別的軸相去了，確定是
         伺服線或動力線有問題，換掉即可。
      (5)如果是回授回路有問題，先把編碼器線和動力線與其他沒有問題軸相的編碼器線
         和驅動器線對換，如果警報跑到兌換過的軸相去了，證明是編碼器線或者動力線
         有問題。換掉即可。
      (6)如果編碼器線和動力線都沒有問題，就把發警報軸相和其他好的軸相的驅動器線
         對換，如果警報跑到其他軸相，證明驅動器線有問題，換過即可。
      (7)如果以上問題都沒問題，再就是懷疑介面和編碼器漏油的問題，這個問題是靠
         經驗判斷，其實編碼器漏油造成的指令丟失情況和軸卡和底座接觸不好的情況
         有些相識；而接頭接觸問題關鍵是把接頭都鎖緊。

進階說明：
      參數561~580的設定即為遺失位置命令的檢查範圍

      如果都為零，一般是機構的問題：如果有不為零的，一般就是電控的問題。

  機構方面的原因：
      (1)如果確定是機構問題，並且無驅動器警報。一般來說，應該是機床缺少潤滑，
         靜摩擦力太大。此時應該檢查機構是不是有卡住及潤滑系統是否良好
      (2)控制器有警報發出，並且伴隨著驅動器警報。此時可能是床台卡死或者
         伺服系統有問題，如果關電重開問題依然存在很明顯，無法動作，應更換伺服
         或者馬達。如果是機構卡死，需要聯繫機械廠家支援

      (1)觀察過8，9，10號參數之後。就做尋點動作(不須重新開機)，尋完原點後，
         觀察24，25，26號參數和40，41，42號參數，如果24，25，26號參數中有不為零的
         ，則回授回路有問題。
      (2)如果40，41，42中有不為零，就是控制器到馬達的線路中有指令丟失。
      (3)如果24，25，26和40，41，42都有不為零的，則信號被干擾的可能性比較大，
         具體表現為在加工中，8，9，10號參數的數值漸漸變大。
         具體故障點可能是cpu板和軸卡接觸不好造成的。可依次換cpu板和軸卡試試。
      (4)如果是控制器到馬達的發動電路有問題，先檢查驅動器線和動力線。
         具體辦法是把懷疑有問題軸相的驅動器線和動力線和其他沒問題軸相的驅動器線
         和馬達線對換，看警報會不會跑到別的軸相去，如果跑到別的軸相去了，確定是
         伺服線或動力線有問題，換掉即可。
      (5)如果是回授回路有問題，先把編碼器線和動力線與其他沒有問題軸相的編碼器線
         和驅動器線對換，如果警報跑到兌換過的軸相去了，證明是編碼器線或者動力線
         有問題。換掉即可。
      (6)如果編碼器線和動力線都沒有問題，就把發警報軸相和其他好的軸相的驅動器線
         對換，如果警報跑到其他軸相，證明驅動器線有問題，換過即可。
      (7)如果以上問題都沒問題，再就是懷疑介面和編碼器漏油的問題，這個問題是靠
         經驗判斷，其實編碼器漏油造成的指令丟失情況和軸卡和底座接觸不好的情況
         有些相識；而接頭接觸問題關鍵是把接頭都鎖緊。
